- "Elderly"/"older patients" = 65 and over; "over N" = strictly older than N. A patient's age is recorded as sphn:Age (sphn:hasQuantity/sphn:hasValue, in years). (common definition; SPHN 2026.1 schema)
- A disease named without a subtype covers its subtypes: name the parent code with the inference option (icd-10-gm:E11 matches E11.9). (organizers' examples)
- Administrative sex is a SNOMED CT class on the code node: male = snomed:248153007, female = snomed:248152002, indeterminate = snomed:32570681000036106. (organizers' example 3; SPHN BMI.rq)
- Durations: bif:datediff("day" | "hour", ?start, ?end) on xsd:dateTime values. (organizers' examples 1, 2, 6, 7)
- Main (principal) diagnosis or procedure: ?record sphn:hasRankCode/rdf:type snomed:63161005 . As a condition: EXISTS { ?record sphn:hasRankCode/rdf:type snomed:63161005 } . (SPHN 2026.1 schema)
- Hospital stay dates: ?case sphn:hasAdmission/sphn:hasDateTime ?admitted ; sphn:hasDischarge/sphn:hasDateTime ?discharged . A prescription reaches its stay through the event that issued it: ?event rdf:type sphn:DrugPrescriptionEvent ; sphn:hasDrugPrescription ?prescription ; sphn:hasAdministrativeCase ?case . ?prescription sphn:hasAdministrationRouteCode ?route_code . (SPHN 2026.1 schema)
- All patients: count the graphs of a record every patient has (?subject rdf:type sphn:SubjectPseudoIdentifier), never ?s ?p ?o. (SPHN All.rq; Query_Compliance.md)
- Which codes (routes, procedures, tests, ...): return and group by the code's class, ?code rdf:type ?concept . FILTER (STRSTARTS(STR(?concept), "http://snomed.info/id/")) (or STR(chop:), STR(icd-10-gm:)), never the code node ?code: a node is a record of one patient, so never GROUP BY it, return it, compare two of them (?a != ?b) or STR() it; compare codes by their classes (?a rdf:type ?k . ?b rdf:type ?k). In the schema, "code under X" (or "code in {X}") names the root of the value set, not a value: match it with ?code rdf:type X OPTION (inference ...), or take the value from ?code rdf:type ?concept. (organizers' examples 6, 7, 10)
- Percentages: ROUND(1000.0 * part / whole) / 10 (ROUND takes one argument). (organizers' examples 3, 4, 8, 9)
- SPARQL has no CASE WHEN, IS NULL, LEAST or GREATEST: use IF(cond, a, b), BOUND(?x) and COALESCE. A flag from another record ("stays with a cholera diagnosis"): BIND(IF(EXISTS { ... }, "yes", "no") AS ?flag), not an OPTIONAL, which repeats the row once per match. (SPARQL 1.1)
